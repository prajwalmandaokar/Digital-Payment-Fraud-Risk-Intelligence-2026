# Power BI Dashboard Guide

Connect: Home -> Get Data -> MySQL database -> Server localhost -> Database upi_intelligence -> Import -> transactions -> Load.

Page 1 Executive Overview: KPI cards for total transactions, total value, average value, high risk and high-risk %. Add monthly trend, risk distribution, state value, transaction type and slicers.

Page 2 Fraud & Risk Analysis: high-risk count/value, average risk score, failed %. Add risk by device, transaction type, app, anomaly type and risk score visuals.

Page 3 Geographic Intelligence: state high-risk map, top 10 cities, State-City matrix and state slicer.

Page 4 Payment Behavior: app volume, bank value, channel high-risk %, transaction size and device risk.

Page 5 Time & Behavior: hour volume, hour high-risk, monthly value and age-band risk.

Add a note: Synthetic dataset; risk/anomaly labels are rule-based for portfolio demonstration and are not real fraud statistics.
